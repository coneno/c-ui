## Required Setup

Add `@c-ui` to your consumer app's `components.json` and use the style matching your component library:

```json
{
  "style": "base-nova",
  "registries": {
    "@c-ui": "https://coneno.github.io/c-ui/r/{style}/{name}.json"
  }
}
```

Both `base-nova` (Base UI) and `radix-nova` (Radix UI) are supported.
The `{style}` placeholder selects the matching registry automatically. Existing
Radix projects can keep their current configuration.

Changing the style does not migrate installed components. For an existing app,
migrate its wrappers and call sites before installing Base UI versions.
See [Migrating to Base UI](/docs/base-ui-migration).

## Install Components

Install a component by alias:

```bash
npx shadcn@latest add @c-ui/loading-button
```

Install multiple components at once:

```bash
npx shadcn@latest add @c-ui/alert-provider @c-ui/confirm @c-ui/dialog
```

Registry index:

`https://coneno.github.io/c-ui/r/base-nova/registry.json`

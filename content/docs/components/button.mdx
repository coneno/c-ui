## Install

The examples use `base-nova`. For Radix, use `radix-nova` in the URL.

```bash
npx shadcn@latest add @c-ui/button
```

Direct URL install:

```bash
npx shadcn@latest add https://coneno.github.io/c-ui/r/base-nova/button.json
```

## Usage

```tsx
import { Button } from "@/components/ui/button";

export function ButtonExample() {
  return (
    <div className="flex flex-wrap gap-3">
      <Button>Default</Button>
      <Button variant="outline">Outline</Button>
    </div>
  );
}
```

## Configuration

| Prop           | Type                                                                                 | Default     | Notes                                         |
| -------------- | ------------------------------------------------------------------------------------ | ----------- | --------------------------------------------- |
| `variant`      | `"default" \| "outline" \| "secondary" \| "ghost" \| "destructive" \| "link"`        | `"default"` | Visual style                                  |
| `size`         | `"default" \| "xs" \| "sm" \| "lg" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg"` | `"default"` | Button sizing                                 |
| `render`       | `ReactElement` or render function                                                    | —           | Compose with a custom element (Base UI)       |
| `nativeButton` | `boolean`                                                                            | `true`      | Set false when rendering a non-button element |
| `className`    | `string`                                                                             | `undefined` | Extends styles                                |

All native `<button>` props are supported.

## Radix API

For `radix-nova`, use `asChild` instead of the Base-only `render` and
`nativeButton` props. The other documented options apply to both styles.

| Prop      | Type      | Default | Notes                                                          |
| --------- | --------- | ------- | -------------------------------------------------------------- |
| `asChild` | `boolean` | `false` | Apply the component props to its single child using Radix Slot |

```tsx
<Button asChild>
  <a href="/settings">Settings</a>
</Button>
```

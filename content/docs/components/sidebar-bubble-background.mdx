```bash

```

## Usage

```tsx
"use client";

import {
  SidebarBubbleBackground,
  type SidebarBubbleBackgroundTheme,
} from "@/components/c-ui/sidebar-bubble-background";

const theme: SidebarBubbleBackgroundTheme = {
  key: "study-alpha",
  hue: 28,
};

export function StudySidebarSurface() {
  return (
    <SidebarBubbleBackground theme={theme} className="flex h-full min-h-0 flex-col">
      <header className="px-4 py-3 text-sm font-medium">Study Name</header>
      <nav className="flex-1 space-y-2 px-3 pb-3">
        <button type="button" className="w-full rounded-xl bg-white/60 px-3 py-2 text-left">
          Overview
        </button>
        <button type="button" className="w-full rounded-xl px-3 py-2 text-left">
          Participants
        </button>
      </nav>
    </SidebarBubbleBackground>
  );
}
```

Changing `theme.key` creates a new layout and crossfades the old layer out.

## SidebarBubbleBackground Props

- `theme`: `SidebarBubbleBackgroundTheme | undefined`. Controls the palette and transition identity.
- `className`: `string | undefined`. Extends the root wrapper when `children` are present, or the absolute background layer when they are not.
- `children`: `ReactNode | undefined`. Optional foreground content rendered above the animated background without extra `z-index` coordination.
- `reducedMotion`: `boolean | null | undefined`. Overrides the media-query result.
- `bubbleCount`: `number | undefined`. Defaults to `12`.
- `blur`: `number | undefined`. Defaults to `50`.
- `motion`: `BubbleBackgroundMotion | undefined`. Overrides the default drift timings.
- `initialSize`: `{ width: number; height: number } | undefined`. Fallback container size before measurement.
- `bubbleSize`: `[number, number] | undefined`. Optional pixel range for generated bubble widths. Defaults to `[180, 360]`.

## SidebarBubbleBackgroundTheme Shape

- `key`: Stable theme key. Changing it triggers a crossfade to a new layout.
- `hue`: Base hue in degrees.
- `hueSpread`: Hue variation across bubbles in degrees. Defaults to `20`.
- `saturation`: Saturation percentage. Defaults to `80`.
- `lightness`: Lightness percentage. Defaults to `70`.
- `opacity`: Bubble opacity from `0` to `1`. Defaults to `0.38`.
- `overlay`: Softening overlay strength from `0` to `1`. Defaults to `0.6`.

## When To Use It

Use `SidebarBubbleBackground` when you want a higher-level sidebar surface that keeps the existing c-ui motion model but manages theme transitions for you. You can keep using it as a background-only layer, or pass `children` when you want the foreground sidebar chrome to live inside the same stable wrapper.

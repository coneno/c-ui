## Install

The examples use `base-nova`. For Radix, use `radix-nova` in the URL.

```bash
npx shadcn@latest add @c-ui/loading-button
```

Direct URL install:

```bash
npx shadcn@latest add https://coneno.github.io/c-ui/r/base-nova/loading-button.json
```

## Usage

```tsx
import { LoadingButton } from "@/components/c-ui/loading-button";
import { useState } from "react";

export function SubmitAction() {
  const [isLoading, setIsLoading] = useState(false);

  const submit = async () => {
    setIsLoading(true);
    await new Promise((resolve) => setTimeout(resolve, 1200));
    setIsLoading(false);
  };

  return (
    <LoadingButton isLoading={isLoading} onClick={() => void submit()}>
      {isLoading ? "Submitting..." : "Submit"}
    </LoadingButton>
  );
}
```

## Configuration

| Prop        | Type                              | Default     | Notes                             |
| ----------- | --------------------------------- | ----------- | --------------------------------- |
| `isLoading` | `boolean`                         | `false`     | Shows spinner and disables button |
| `variant`   | same as `Button` variants         | `"default"` | Forwarded to base button          |
| `size`      | same as `Button` sizes            | `"default"` | Forwarded to base button          |
| `render`    | `ReactElement` or render function | —           | Forwarded to the Base UI button   |

All native `<button>` props are supported and forwarded.

## Radix API

For `radix-nova`, use `asChild` instead of the Base-only `render` and
`nativeButton` props. The other documented options apply to both styles.

| Prop      | Type      | Default | Notes                                                          |
| --------- | --------- | ------- | -------------------------------------------------------------- |
| `asChild` | `boolean` | `false` | Apply the component props to its single child using Radix Slot |
